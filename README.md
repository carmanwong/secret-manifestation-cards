# The Secret Manifestation Cards

An interactive manifestation card application based on "The Secret" by Rhonda Byrne.

## Features
- **Oracle Mode**: Draw a card to receive guidance.
- **Library Mode**: View all collected truths.
- **Pure Traditional Chinese UI**: Tailored for Chinese speakers.

## Versions
- `secret_oracle_v6.html`: The latest and most stable version with hardcoded card data.

## How to use
Simply open `secret_oracle_v6.html` in any modern web browser.
